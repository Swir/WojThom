# WojThom Web

Responsive browser version of WojThom 6.0.

## Run

You can open `index.html` directly or serve this directory using any static HTTP server.

## Current state

- responsive desktop/mobile UI
- Work / History / Statistics / Settings navigation
- parser compatible with the new Android parser
- ranges such as `08:00 - 16:00`
- decimal hours such as `7.5h`
- durations such as `08:30`
- automatic total calculations and validation
- edit/delete entries
- local history with restore/delete
- basic statistics
- light/dark theme
- localStorage persistence
