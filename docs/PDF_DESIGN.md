# WojThom APEX PDF design

The PDF report is intentionally kept clean and professional for real work-time reporting.

## Layout principles

- A4 portrait with safe print margins
- strong WojThom APEX header without wasting vertical space
- report period and generation date visible at a glance
- numbered work-time rows
- alternating table rows for scanability
- compact summary cards for total time, work days, entries and daily average
- repeated table header after page breaks on Android
- page number and WojThom branding in the footer
- independent PL / EN / NO report language

Android and Web should keep the same visual hierarchy even though they use different PDF/print engines.
